# xina-4-uslub

Bitta talking-head videodan **4 ta premium Reels** (9:16, 1080×1920, 60 fps, −14 LUFS) yasaydigan skill —
@xina_siren (Toshkent, halol xina / manikyur studiyasi) uchun qurilgan, istalgan go'zallik/ekspert videosiga moslanadi.

| | Uslub | Qisqacha |
|---|---|---|
| A | **Xina chizig'i** | xina konusidan chizilgan yozuv va mehndi naqsh, chiziq pasta rangidan dog' rangiga o'tadi |
| B | **Binafsha ipak** | jurnal muqovasi, Bodoni + Jost, muzli shisha, lavanda ipak o'tishi |
| C | **Original pasport** | gilosh hujjat, golografik HALOL muhri, UV-skaner, «YOPILDI» sertifikat |
| D | **Kundalik** | qo'lyozma qaydlar, skotch, chek-list, polaroid, yirtiq qog'oz |

**Quvur:** Auphonic shovqin tozalash → mutaxassisning aynan so'zlari bilan subtitr (whisper uz/kk/tr + MMS forced alignment, so'zma-so'z vaqt)
→ asl 4K'dan yuz retushi → kesim va yuz zonalari → HyperFrames + GSAP (overshootsiz) → render → loudnorm.
